# Pre Entrega Automation Testing

## Propósito

Proyecto de automatización QA utilizando Selenium y Pytest sobre SauceDemo.

Casos automatizados:

- Login
- Validación catálogo
- Carrito de compras

---

## Tecnologías

- Python
- Selenium
- Pytest
- Pytest HTML
- Git
- GitHub

---

## Instalar dependencias

pip install -r requirements.txt

---

## Ejecutar pruebas

pytest -v

---

## Generar reporte HTML

pytest tests/test_saucedemo.py -v --html=reports/reporte.html
